# Sistema Inteligente de Búsqueda de Rutas

## Descripción
Este proyecto implementa un sistema inteligente basado en conocimiento para encontrar la mejor ruta entre dos estaciones dentro de un sistema de transporte.

El sistema utiliza Python para representar una red de estaciones mediante un grafo y aplica un algoritmo de búsqueda para determinar la ruta más eficiente entre un punto de origen y un destino.

## Funcionamiento
Cada estación está conectada con otras estaciones cercanas y cada conexión tiene un costo asociado que representa el tiempo estimado de viaje en minutos.

El programa analiza estas conexiones y calcula la ruta con el menor costo total.

## Tecnologías utilizadas
- Python
- Algoritmo de búsqueda de rutas
- Estructuras de datos (grafo y cola de prioridad)
